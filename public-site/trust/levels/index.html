Trust-mark levels

  1. Compatible — interop tests. Not “protected.”
  2. Verified Workflow — configuration baseline at a point in time.
  3. Protected Workflow — continuous controls for a named scope only.
  4. Independently Assessed — external firm, exact versions.
QEV Protected Workflow means the specific workflow and systems named in the linked certificate met stated controls during the certificate period. It is not a company-wide security guarantee.

Stronger trust marks require assessment — Trust program · Audit status.
