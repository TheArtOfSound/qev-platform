QEV Trust Program

Important: A badge graphic proves nothing. Only a linked signed certificate with live status is the trust object. Badges are scoped to a named workflow — never “the whole company is secure.”

Two trust objects

  1. Evidence-package seal — per sealed package (hash, signatures, completeness, gaps).
  2. Company workflow certificate — exact assessed workflow only, with expiration and revocation.

Levels

  1. QEV Compatible — format / interoperability tests.
  2. QEV Verified Workflow — configuration baseline (not yet public-issuable at scale).
  3. QEV Protected Workflow — continuous controls (not yet issuable).
  4. QEV Independently Assessed — external firm (not yet issuable).

Today’s public product is a controlled-use preview: no formal third-party audit, no KMS/HSM, no formal key rotation/revocation. Therefore only Compatible and internal Pilot Configuration Passed may be issued from the gateway pilot tooling.

Example scope text

Allowed wording:

QEV Pilot Configuration Passed — Field-service estimates, approvals, job photos, change orders, invoices, and completion records.

Not allowed:

Example Co is QEV Protected / fully secure.
