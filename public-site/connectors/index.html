Connectors

Normalize vendor events into qev.event.v1 for the customer-controlled gateway.

Labels are the same ones used on /status/: Available — works today on a public or pilot surface · Preview — controlled use, limited trust model, not enterprise-hardened · Planned — designed or scaffolded, not ready for production claims · Not assessed — no independent third-party security audit. A directory existing in the monorepo is not the same as a connector running.

Connector Label What is true today
generic_webhook Available (pilot) Signed HTTP webhooks into POST /v1/webhooks/{connector_id}, HMAC-SHA256 over the raw body. Reported by the pilot gateway as enabled and healthy.
job_portal Available (pilot) Job/work-order events from the pilot portal path. Reported by the pilot gateway as enabled and healthy.
photo_file Available (pilot) Photo and document artifacts attached to a case. Reported by the pilot gateway as enabled and healthy.
Local folder watch (file-watch) Preview Not a separate connector — it is an option on photo_file, switched on by setting watch_dir in gateway settings. Implemented in the monorepo, but the hosted pilot's health response does not report a watch directory, so do not assume it is switched on there.
github Planned Directory and README exist in the monorepo and the README says “planned.” No connector is registered in the gateway and the pilot does not list it. Not usable in a pilot today.
otlp Planned Directory and README exist in the monorepo and the README says “planned.” No connector is registered in the gateway and the pilot does not list it. Not usable in a pilot today.
OAuth Drive / M365, Clio, DocuSign Planned Named in flow definitions only. No connector code in the monorepo.
Connector certification harness Planned An engineering-backlog item for testing connector releases. It is not a connector and not a capture path — do not count it as one.
Independent security assessment of any connector Not assessed None completed — see Audit status.
Check the list yourself before sizing a pilot.
The hosted pilot gateway publishes its own connector list:
curl -s https://secure.imagineqira.com/platform/v1/health
Read the connectors object in the response. Only connectors listed there exist on that instance. Anything on this page not labelled Available cannot carry pilot scope. The same response reports the instance mode and whether capture is enabled; in shadow mode the gateway records alongside normal operations and never controls or blocks a business process.
